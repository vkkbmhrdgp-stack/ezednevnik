# Ежедневник

Личный ежедневник с тёмным интерфейсом: задачи по дням, цели, заметки.
Работает как сайт и ставится как приложение (PWA) на телефон и компьютер.
Данные хранятся локально в браузере — ничего никуда не отправляется.

## Что умеет

- **Дни** — задачи на конкретную дату, неделя с прогрессом сверху, календарь месяца сбоку
- **Зачёркивание** — клик по чекбоксу, задача уезжает в «Выполнено» с анимацией
- **Приоритеты** — обычная / важная / срочная
- **Перетаскивание** — порядок задач внутри дня меняется мышкой
- **Перенос** — одна задача или все незакрытые уезжают на следующий день
- **Цели** — долгие цели с прогресс-баром, к цели можно привязывать задачи
- **Заметка дня** — свободный текст под задачами
- **Поиск** по всем задачам за все дни (<kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> или <kbd>/</kbd>)
- **Серия дней** подряд, где всё закрыто, и общий счётчик
- **Бэкап** — выгрузка и загрузка всех данных одним JSON-файлом
- **6 цветов акцента**, адаптив под телефон, офлайн-режим

### Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | предыдущий / следующий день |
| <kbd>Enter</kbd> | фокус в поле новой задачи |
| <kbd>T</kbd> | вернуться на сегодня |
| <kbd>G</kbd> | цели |
| <kbd>/</kbd> или <kbd>Ctrl</kbd>+<kbd>K</kbd> | поиск |
| двойной клик по задаче | редактировать текст |

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка статики:

```bash
npm run build    # результат в dist/
npm run preview  # посмотреть собранную версию
```

Папку `dist/` можно закинуть на любой статический хостинг (GitHub Pages, Netlify,
Vercel) или открыть локально через любой веб-сервер.

## Как поставить приложением

- **Android / Chrome:** открыть сайт → меню → «Установить приложение»
- **iPhone / Safari:** «Поделиться» → «На экран "Домой"»
- **Windows / macOS, Chrome или Edge:** значок установки в адресной строке

После установки открывается в своём окне, без адресной строки, и работает без интернета.

## Стек

TypeScript + React 18 + Vite. Никаких серверов и баз: состояние лежит в
`localStorage`, обновления идут через лёгкий стор на `useSyncExternalStore`,
так что перерисовывается только то, что изменилось.

## Где лежат данные

В `localStorage` браузера под ключом `ezednevnik.v1`. Чистка данных сайта их
удалит — для переноса на другое устройство есть кнопки «Бэкап» и «Загрузить».
